RAT - Repository Analysis Tool

Point RAT at a Git repository and it shows who changed what, when and by how much. Every figure is computed from Git's own history and explained in plain English - no Git knowledge needed. Add several repositories and compare them side by side.

New here? The Help & glossary explains every term, number and chart in this tool.

Five views, one story

Overview shows the big picture: totals, activity over time and top contributors. Files ranks every changed file. Directories lets you browse folder by folder. Commits shows the raw history, and Authors shows who did what.

Numbers you can trust

Line counts come from Git's own diff machinery: rename detection, binary files excluded and merge commits handled exactly as the COMS3011A definitions require.

Slice it your way

Filter by date range or a single author, hand-pick commits into custom sets, merge duplicate identities, and export any table to CSV.

1. Add a repository

1a. Clone from URL public repositories

Paste the full web address of a public repository (GitHub, GitLab...). The complete history is downloaded, so large projects can take a few minutes - indexing runs in the background. Private repositories won't work: the tool never logs in.

1b. Upload zip made from a clone

The zip must contain the repository's hidden .git folder (that's where the history lives). Heads-up: GitHub's green Download ZIP button does not include it - see the Help page for the working way to make a zip.
